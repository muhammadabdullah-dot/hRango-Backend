## 12. Manpower planning [mp]

Source: Figma "HRango Dashboard App Version", page App UI (Manpower Planning frames), read 2026-10-19;
completed 2026-10-23 for the backend build (comparison/09-manpower-benefits.md records each decision).
Approval is status based inside mp (Budget Approvals screen), not through req.request: a budget is for a
department, not for an employee, and req.request.employee_id is required.

```
budget_duration                       E-Budget Settings -> Budget Duration; the "Plan Year" of plans and budgets
  id                PK
  company_id        FK company
  name                                "2024", "2024-2025"
  start_date        {NN}
  end_date          {NN}
  is_current                          IsCurrentBudgetDurationPeriod: at most one per company (kept by mp.usp_budget_duration_save)
  UNIQUE (company_id, name)

position                              E-Budget Settings -> Employee Position: an approved seat
  id                PK
  company_id        FK company
  code                                given, or the next POS-0001 number
  branch_id         FK branch         shown as "Station" (required on the form)
  job_title_id      FK job_title      {NN} shown as "Position Title" (org.job_title)
  employee_group_id FK employee_group  required on the form
  division_id       FK division       optional
  department_id     FK department
  sub_department_id FK department
  cost_center_id    FK cost_center
  grade_id          FK grade
  reports_to_id     FK position
  employee_id       FK employee       who holds it, blank if open
  status                              active, inactive

position_salary_range                 the Min / Max Salary of the Employee Position form, kept over time
  id                PK
  position_id       FK position
  effective_date    {NN}              the band in force is the latest one on or before the day asked about
  min_salary        {NN}
  max_salary        {NN}
  UNIQUE (position_id, effective_date)

manpower_plan                         "Add Planning"; saving submits it and makes its budgets
  id                PK
  company_id        FK company
  title
  budget_duration_id FK budget_duration   shown as "Plan Year"; "Current Planning" is its is_current
  division_id       FK division       optional
  branch_id         FK branch         "Station"
  department_id     FK department
  sub_department_id FK department
  employee_group_id FK employee_group
  description
  monthly_amount    {NN}              sum of the lines' total_salary (computed by the procedure)
  annual_amount     {NN}              sum of the lines' annual_gross (computed by the procedure)
  status                              pending, approved, rejected (follows its budgets)
  submitted_at

manpower_plan_line                    Plan for New Positions (kind new_position) / Existing Positions (existing_employee)
  id                PK
  manpower_plan_id  FK manpower_plan
  kind                                new_position, existing_employee
  sort_order
  position_id       FK position       new-position lines
  employee_id       FK employee       existing-employee lines
  e_budget_id       FK e_budget       the budget this line is counted in
  headcount         {NN}              vacancies on a new-position line; 1 on an existing-employee line
  start_date        {NN}              "Plan Date" from (first day of the month)
  end_date          {NN}              "Plan Date" to; both inside the plan year
  months            {INT} {NN}            calendar months from start to end, both counted
  min_salary, max_salary              new positions: the band, defaulted from position_salary_range
  monthly_salary                      existing employees: defaulted from hr.employee_salary
  total_allowance   {NN}
  total_salary      {NN}              a month: (max_salary + allowance) x headcount, or monthly_salary + allowance
  annual_gross      {NN}              total_salary x months

e_budget                              "E-Budgeting" list and "Budget Approvals"
  id                PK
  company_id        FK company
  budget_duration_id FK budget_duration
  manpower_plan_id  FK manpower_plan  optional: blank for a budget added by hand
  job_title_id      FK job_title      the position title the money is for
  department_id     FK department     rows are per department in the samples
  title
  amount            {NN}
  total_positions   {NN}              new seats it opens once approved
  start_date        {NN}
  end_date          {NN}
  status                              pending, approved, rejected
  decided_by_user_id FK user_account
  decided_at
  remarks

open_position                         positions released for hiring when a budget is approved
  id                PK
  company_id        FK company
  e_budget_id       FK e_budget
  manpower_plan_line_id FK manpower_plan_line
  position_id       FK position
  job_title_id      FK job_title
  department_id     FK department
  branch_id         FK branch
  title
  approved_positions {NN}             seats the budget approved
  total_positions   {NN}              seats open now (Edit)
  end_date
  jd_file_id        FK stored_file    "JD's" download
  status                              active, closed
```

```
budget_duration 1──* manpower_plan 1──* manpower_plan_line ──> position
budget_duration 1──* e_budget 1──* manpower_plan_line
manpower_plan 1──* e_budget 1──* open_position 1──* job_position
position 1──* position_salary_range
position ──> position (reports to)
```
