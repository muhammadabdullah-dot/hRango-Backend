## 15. Project and task management [pm]

Sources: Functional Requirements PDF pp. 181-257 (Project and Task Management BRD), the Create Workspace
wizard and Project Workspace Figma files (requirements/HRango - Project Management Module,
requirements/HRango - Project Workspace UX UI Design). Decisions: comparison/08-projects.md.

Workspace roles (workspace_member.member_role, column_permission.member_role): workspace_admin, hr,
manager, team_leader, contributor. They decide what a member may do inside a workspace; the company
roles (auth) only open the module and its screens.

```
template                              reference data: the four workflow templates (Define Workflow) and the five status templates (Edit Statuses)
  id PK, template_kind {NN}, code, name, description, sort_order
  UNIQUE (template_kind, code)

template_item                         what a template starts with: a view, a status or an organizer feature
  id                PK
  template_id       FK template
  item_type         {NN}              view, status, feature
  item_code         {NVARCHAR(50)}    view or feature code; blank for a status
  name                                status name, or the label of the view or feature
  status_group                        statuses: not_started, active, done, closed
  color
  sort_order
  is_default                          views: the view a workspace opens on

workspace
  id                PK
  company_id        FK company
  name                                3 to 50 characters, unique in the company
  description                         up to 300 characters
  privacy           {NN}              private (members only), workspace (everyone in the company), public (everyone in the company reads, members edit)
  department_id     FK department     Define Workflow: Select Your Department
  workflow_template_id  FK template {NN}  work_starter, project_management, marketing_team, product_engineering
  status_mode       {NN}              default, custom
  status_template_id  FK template      custom statuses started from this status template
  owner_id          FK employee {NN}  Workspace Owner; always a member with workspace_admin
  cover_file_id     FK stored_file
  UNIQUE (company_id, name)

workspace_member
  workspace_id FK workspace, employee_id FK employee, member_role {NN}

workspace_status                      the workspace's task statuses, in four groups
  id PK, workspace_id FK workspace, status_group {NN}, name, color, sort_order, wip_limit {INT}
  UNIQUE (workspace_id, name)

workspace_feature                     organizer features switched on (priority, tags, time_tracking, story_points, wip_limits ...)
  id PK, workspace_id FK workspace, feature_code {NVARCHAR(50)} {NN}, setting_value
  UNIQUE (workspace_id, feature_code)

folder
  id PK, workspace_id FK workspace, name, sort_order
  UNIQUE (workspace_id, name)

task_list                             a list (the BRD's "project"): colour, description up to 500, priority, start and end
  id PK, workspace_id FK workspace, folder_id FK folder, name, privacy, color, description, start_at, end_at, priority, sort_order
  UNIQUE (workspace_id, name)

task_list_member                      who may see a private list (besides workspace admins and HR)
  task_list_id FK task_list, employee_id FK employee

sprint                                not in the first build (Sprints column marked Skipped in the design)
  id PK, workspace_id FK workspace, name, start_date, end_date

task
  id                PK
  company_id        FK company
  workspace_id      FK workspace
  task_list_id      FK task_list      blank: at the workspace's top level
  parent_task_id    FK task           subtask
  code                                HR000000001, per company
  name, description
  task_type         {NN}              task, milestone
  status_id         FK workspace_status {NN}
  priority                            urgent, high, normal, low
  start_date, start_time
  due_date, due_time
  original_due_date                   the due date before an approved extension
  time_estimate_minutes
  rating            {INT}             1 Fair, 2 Good, 3 Excellent Results
  url               {NVARCHAR(2000)}  URL Connection
  recurrence                          JSON: every, unit, weekdays, ends
  sprint_id         FK sprint
  cover_file_id     FK stored_file
  sort_order
  closed_at                           set when the status moves into the done or closed group
  is_closed_late                      completed after the due date without an approved extension (story point impact)

task_assignee      task_id FK task, employee_id FK employee, story_points
task_dependency                       stored as "task waits on other task"; Blocking is the same row seen from the other side
  id PK, task_id FK task, other_task_id FK task {NN}, kind
  UNIQUE (task_id, other_task_id)
tag
  id PK, workspace_id FK workspace, name, color
  UNIQUE (workspace_id, name)
task_tag           task_id FK task, tag_id FK tag
checklist_item     id PK, task_id FK task, item_text {NN}, is_done, sort_order
time_entry                            a running timer has no end_at yet
  id PK, task_id FK task, employee_id FK employee {NN}, start_at {NN}, end_at, minutes, notes

task_comment
  id                PK
  task_id           FK task
  author_id         FK employee {NN}
  body              {NN}
  parent_id         FK task_comment   reply
  assigned_to_id    FK employee       Assigned to ... by ...
  assigned_by_id    FK employee
  resolved_by_id    FK employee       Mark as Resolve
  resolved_at
  edited_at

comment_mention                       @person or #task in a comment
  id PK, comment_id FK task_comment, employee_id FK employee, mentioned_task_id FK task

comment_reaction                      like or emoji, one per person per comment
  comment_id FK task_comment, employee_id FK employee, reaction {NVARCHAR(30)} {NN}

reminder                              stored only; nothing is sent yet
  id                PK
  workspace_id      FK workspace
  entity_type       {NN}              task, task_list, workspace
  entity_id         {NN}
  name
  owner_id          FK employee {NN}
  assignee_id       FK employee
  remind_at         {NN}
  notify_before_minutes
  reminder_kind                       soft, hard
  notified_at

task_extension                        Request Extension: one per task; approved keeps story points
  id PK, task_id FK task, requested_by_id FK employee {NN}, old_due_date, new_due_date {NN}, reason, status, decided_by_id FK employee, decided_at, remarks, request_id FK request

custom_field                          Add Fields
  id PK, workspace_id FK workspace, name, field_type {NN}, description, config, sort_order
  UNIQUE (workspace_id, name)

column_permission                     Set Role Permission on a List view column; blank role and person = the workspace default
  id                PK
  workspace_id      FK workspace
  column_key        {NVARCHAR(50)} {NN}  built-in column key, or cf_<custom_field id>
  member_role                         blank, or one workspace role
  employee_id       FK employee       a custom permission for one member
  permission_level  {NN}              can_edit, can_view, private

task_field_value   task_id FK task, custom_field_id FK custom_field, field_value

list_view                             views of a workspace (task_list_id blank) or of one list
  id PK, workspace_id FK workspace, task_list_id FK task_list, owner_id FK employee, view_type {NN}, name, config, is_pinned, is_private, is_protected, is_default, is_required, sort_order

share_link                            Sharing and Permissions; stored, nothing is sent
  id                PK
  workspace_id      FK workspace
  entity_type       {NN}              task, task_list, workspace
  entity_id         {NN}
  share_scope       {NVARCHAR(30)}    list (single list view), page (whole page)
  token             {NN}
  is_public                           Share link with anyone
  allow_open_tasks
  valid_from, valid_to
  max_access, access_count
  properties                          JSON: task properties shown
  UNIQUE (token)
  UNIQUE (entity_type, entity_id)

share_member
  id PK, share_link_id FK share_link, employee_id FK employee, email, access_level {NN}

favorite                              Add to Favorites and Hide, per person
  id PK, employee_id FK employee, entity_type {NN}, entity_id {NN}, kind
  UNIQUE (employee_id, entity_type, entity_id, kind)

doc                                   not in the first build (no design)
  id PK, workspace_id FK workspace, title, body, visibility
note                                  not in the first build (no design)
  id PK, owner_id FK employee, title, body, archived_at
```

```
template 1──* template_item
workspace 1──* folder 1──* task_list 1──* task 1──* task (subtask)
workspace *──* employee (workspace_member)
workspace 1──* workspace_status / workspace_feature / tag / custom_field / column_permission / list_view
task *──* employee (task_assignee)
task 1──* time_entry / task_comment / checklist_item / task_dependency / task_extension
task_comment 1──* comment_mention / comment_reaction
custom_field 1──* task_field_value
share_link 1──* share_member
```
